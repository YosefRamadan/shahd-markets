PHP 8 + MySQL

أسواق شهد الفيوم

هذا المشروع تم تحويله إلى تطبيق PHP 8 + MySQL مخصص للاستضافة على InfinityFree. لا يحتوي على خطوة بناء Node.js، ولذلك لا يمكن تشغيله داخل المعاينة هنا — المعاينة تعمل بـ Node/Vite فقط ولا تحتوي على مفسّر PHP.

لتشغيل الموقع فعلياً:

  1. ارفع الملفات إلى مجلد htdocs على InfinityFree.
  2. أنشئ قاعدة بيانات MySQL واستورد database/schema.sql.
  3. عدّل بيانات الاتصال في config/config.php.
  4. أنشئ حساب المدير حسب docs/deployment-guide.md.
  5. افتح الموقع ثم /admin/login.
